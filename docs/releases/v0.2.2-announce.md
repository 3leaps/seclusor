# Seclusor v0.2.2

**Type a secret without it showing on screen.**

v0.2.2 is a compatibility release. Interactive `secrets set --value-stdin`
now hides keystrokes and finishes on Enter. Scripts that pipe or redirect
values do not change. LF/CRLF passphrase-file line endings now behave
consistently across Windows and Unix. Encrypted writes warn if none of the
identities already loaded for the command belong to the target recipient set.

Document formats and Rust, Go, TypeScript, and C-ABI contracts are unchanged.
If your automation already pipes values, this is a drop-in upgrade.

**Upgrade** (after the GitHub release is published):

```bash
brew upgrade seclusor
scoop update seclusor
```

First install: `brew install 3leaps/tap/seclusor` or see the [README](../../README.md).
Prefer verifying GitHub release assets with an expected public key
(`seclusor assets verify`).

If you are still on v0.2.0 or earlier, installing v0.2.2 also includes the
v0.2.1 `secrets run` fix. That advisory is
[GHSA-2w88-3q86-736g](https://github.com/3leaps/seclusor/security/advisories/GHSA-2w88-3q86-736g).
This release does not reopen it.

Full notes: [v0.2.2 release notes](v0.2.2.md).
