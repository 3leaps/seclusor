# Seclusor v0.2.3

**Encrypted pack sealing, clean child environments, macOS ACL guards, and signed release provenance.**

v0.2.3 is a hardening and release-provenance update. `secrets set`, `unset`, and
`import-env` now fail closed if recipient flags are passed against an
unencrypted plaintext file (previously, `secrets set --recipient-file` against a
plaintext document created via `secrets init` without `--codec bundle` ignored
the recipient flag and wrote the value in plaintext). `secrets init --codec inline`,
`-` stream support on `secrets inline encrypt`, and repeatable `--recipient-file`
are now supported. `secrets run --clean-env` and `--env-allow` scrub ambient
parent environment variables before launching a child process. On macOS, private
file writes clear inherited extended ACLs and loads warn on non-owner ACL grants
(`ls -le` / `chmod -N`). v0.2.3 is also the first release published with
OpenPGP-signed dual annotated tags (`v0.2.3` and
`bindings/go/seclusor/v0.2.3`), `decernor` fingerprint anchors, and Go 1.27+ FFI
bitcode stripping.

Document formats and Rust, Go, TypeScript, and C-ABI contracts are unchanged.

**Upgrade** (after the GitHub release is published):

```bash
brew upgrade seclusor
scoop update seclusor
```

First install: `brew install 3leaps/tap/seclusor` or see the [README](../../README.md).
Prefer verifying GitHub release tags, public keys, and signed checksum manifests
against the committed `decernor` fingerprint anchors (see
[Release Signing and Verification](../security/README.md)).

If you are still on v0.2.0 or earlier, installing v0.2.3 also includes the
v0.2.1 `secrets run` fix. That advisory is
[GHSA-2w88-3q86-736g](https://github.com/3leaps/seclusor/security/advisories/GHSA-2w88-3q86-736g).
This release does not reopen it.
