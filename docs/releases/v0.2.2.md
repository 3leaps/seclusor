# Release Notes — v0.2.2

**Release Date**: August 17, 2026

**Status**: Safer interactive entry; same document and library contracts

## Overview

Seclusor v0.2.2 is a compatibility release. The headline change is human:
when you type a secret at a terminal prompt, it no longer appears on screen.

`secrets set --value-stdin` now shows a `Value:` prompt, hides keystrokes, and
finishes on Enter. Scripts that pipe or redirect values keep the same
byte-stream behavior they already have. Ordinary passphrase files with LF or
CRLF line endings now behave consistently across Windows and Unix. Encrypted
writes warn if none of the identities already loaded for the command belong to
the target recipient set.

Internal signing and build dependencies are refreshed. Document formats,
ciphertext, and Rust, Go, TypeScript, and C-ABI contracts are unchanged. If your
automation already pipes values, treat this as a drop-in upgrade.

## Who this is for

- **Operators** who type secret values at a prompt and do not want them
  echoed to the terminal
- **Automation owners** who share passphrase files across Unix and Windows
- **Teams** writing encrypted documents after identity rotation, who want a
  heads-up before they retire an old identity
- **Integrators** who need a dependency refresh without a format or API
  change

## Highlights

### Type a secret without it showing on screen

On a terminal, `secrets set --value-stdin` now:

- prompts `Value:`
- hides keystrokes
- accepts Enter
- restores the terminal after success, errors, interrupts, and unwinding

Use `--echo-value` only when you _want_ to see what you type. That switch
requires `--value-stdin` on a terminal. In that explicit visible mode, input
still ends on EOF (Ctrl-D on Unix), not Enter. Piped or redirected stdin is
unchanged and rejects `--echo-value`.

This controls **input visibility**. It is not `secrets get --reveal`, which
controls whether a stored value is printed.

### LF/CRLF passphrase files work consistently across Windows and Unix

Interactive, file, and stdin passphrase channels now remove one trailing LF
or CRLF and reject a value that is empty after that step. A passphrase file
saved on Windows no longer surprises a Unix unlock, and the reverse.

The environment channel (`--passphrase-env`) still takes the exact bytes you
give it. Keep that for the narrow case where an older identity was created
from a CRLF-terminated file: unlock with the exact original value, create a
replacement identity using file or stdin input, rekey, retire the old
identity, and unset the variable. Prefer file or stdin for everyday use.

### A warning before you lock yourself out

Encrypted `set` and `import-env` now emit the same advisory `rekey` already
used: none of the identities already loaded for this command belong to the
target recipient set. The notice does not load extra identities and is not a
decryptability guarantee. Recipient-set validation still runs independently
and still fails closed where required.

If you see the warning, decrypt the result with an identity for the target
set _before_ you retire an old identity.

### Same envelopes, newer internals

- Private Ed25519, SHA-256, and entropy dependencies behind the existing
  signing wrappers
- Byte-exact coverage for signing vectors and versioned envelope fixtures
- First-party error derives updated
- Embedded-docs build manifest moved from YAML to JSON (build-only; no
  document-format change)

The signing envelope version, canonical bytes, public signing APIs, and
verification behavior are unchanged.

## Upgrade notes

| If you…                                             | Then…                                                                                                                                                                                                                                                                       |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Type values at a prompt with `--value-stdin`        | Press **Enter** when you are done. The value is hidden. Add `--echo-value` only if you need visible typing (that mode still ends on EOF).                                                                                                                                   |
| Pipe or redirect `--value-stdin`                    | No script change. Do not add `--echo-value`.                                                                                                                                                                                                                                |
| Share passphrase files across Windows and Unix      | Use `--passphrase-file` or `--passphrase-stdin`. Use `--passphrase-env` only when you need exact original bytes.                                                                                                                                                            |
| Write encrypted documents after rotating identities | Treat a self-lockout warning as a cue to verify decryptability. It is not a yes/no safety verdict.                                                                                                                                                                          |
| Consume Rust, Go, TypeScript, or C-ABI APIs         | Drop-in. Public contracts and document formats are unchanged.                                                                                                                                                                                                               |
| Are still on v0.2.0 or earlier                      | Install **v0.2.2**. You also receive the v0.2.1 `secrets run` fix. See [GHSA-2w88-3q86-736g](https://github.com/3leaps/seclusor/security/advisories/GHSA-2w88-3q86-736g) for that earlier advisory (ranges, severity, current CVE status). This release does not reopen it. |

## Compatibility

- Document schema and ciphertext formats are unchanged.
- Rust, Go, TypeScript, and C-ABI public API contracts are unchanged.
- Existing signing envelopes remain byte-compatible with the updated signing
  and digest dependencies.
- Piped and redirected `--value-stdin` behavior is unchanged.
- **Intentional terminal behavior change:** interactive `--value-stdin` is
  hidden by default and ends on Enter. Explicit `--echo-value` keeps visible
  input and the existing EOF terminator.
- Environment passphrases remain exact-byte inputs; interactive, file, and
  stdin passphrases now normalize one trailing LF or CRLF.

## Security and operational notes

v0.2.1 already shipped the `secrets run` child-environment fix. The published
advisory is
[GHSA-2w88-3q86-736g](https://github.com/3leaps/seclusor/security/advisories/GHSA-2w88-3q86-736g).
See it for affected versions, severity, and current CVE status. v0.2.2 does
not reopen that advisory. Install v0.2.2 for the input and operator-guidance
improvements in _this_ release (and the 0.2.1 fix if you have not taken it
yet).

Keep in mind:

- `--echo-value` shows what you type and still ends on EOF; hidden terminal
  input is the default.
- A self-lockout warning is advisory. Verify decryptability after a recipient
  change and before retiring old identities.
- `--passphrase-env` remains present in the parent process environment for
  that invocation. Prefer file or stdin channels for ordinary use.
- This release does not add identity rotation automation or a general clean
  child-environment mode.

## Distribution

### Release assets

- Linux amd64 and arm64
- macOS arm64
- Windows amd64 and arm64
- SHA-256 and SHA-512 checksum manifests, signatures, and `release-key.asc`

Prefer verifying GitHub release assets with an expected public key or
fingerprint (`seclusor assets verify`).

### First install

After the GitHub release is published:

```bash
brew install 3leaps/tap/seclusor

scoop bucket add 3leaps https://github.com/3leaps/scoop-bucket
scoop install seclusor
```

### Already installed

```bash
brew upgrade seclusor
scoop update seclusor
```

### Go module

```bash
go get github.com/3leaps/seclusor/bindings/go/seclusor@v0.2.2
```
